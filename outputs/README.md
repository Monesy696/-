# 结果文件索引

本目录由仓库根目录的 `main.py` 统一生成。原始题目与附件位于 `A题.pdf` 和 `附件/`，生成程序不会改写原始附件。

| 文件 | 内容 | 时间与空间分辨率 |
|---|---|---|

| `result2.xlsx` | 问题二温度与水分浓度 | 1 s，0.1 cm |

## 论文材料

- `tables/`：题目表1至表6的CSV数据。
- `figures/`：图1至图7的600 dpi PNG和矢量PDF。
- `figure_data/`：图表对应的可复现CSV数据。
- `validation/`：网格、时间积分、守恒、灵敏度和效应分解结果。
- `A题_综合优化最终建模报告.md`：四问模型、正式结果与验证说明。
- `../output/pdf/A题_表1至表6已填.pdf`：保持原题版式并填入表1至表6的成品PDF。

## 复现

在仓库根目录安装依赖后执行：

```text
python main.py
python fill_tables_pdf.py
```

`main.py`先生成Excel、CSV和图表，`fill_tables_pdf.py`再将表1至表6排入题目PDF。
